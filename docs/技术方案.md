# 药明白 —— 技术方案

> 版本：v0.4 ｜ 更新：2026-11-21 ｜ 配套文档：[产品设计.md](./产品设计.md)

## 总体架构

纯前端单页应用，无后端、无网络依赖（语音与存图均为浏览器原生能力）。

```
React SPA (Vite 构建)
├── 编辑区（受控表单）──┐
│   └─ 成员切换栏（MemberTabs）│
│                      ├── 共享状态（useMembers：多成员药单 + localStorage 持久化）
└── 卡片预览（实时渲染）┘
        ├── html2canvas → PNG 下载
        ├── speechSynthesis → 慢速朗读
        ├── @media print → A4 打印
        └── #share= 只读分享链接（base64url 编码当前成员药单）
构建产物 → 部署到 Qoder Sites（静态托管，公开访问）
```

## 技术栈

| 项 | 选型 | 理由 |
|---|---|---|
| 框架 | React 18 + Vite | Prompt 指定 React；Vite 构建 SPA 标准方案 |
| 样式 | Tailwind CSS | Prompt 指定；适老化大字排版用工具类最直接 |
| 存图 | html2canvas | Prompt 指定 |
| 朗读 | Web Speech API | 浏览器原生，无需 TTS 服务 |
| 测试 | Vitest + React Testing Library | Vite 生态配套，组件级测试 |
| 部署 | Qoder Sites 静态托管 | 大赛要求公开免登录访问 |

## 数据模型

```js
// 单条药品
{
  id: string,
  name: string,          // 药名
  times: string[],       // ['早','中','晚','睡前'] 至少 1 项
  dose: string,          // 每次用量，如 "1片"
  meal: '',              // '饭前'|'饭后'|'随餐'|''
  pillIcon: 'white' | 'yellowOval' | 'redCapsule' | 'blueCapsule' | 'granules',
  note: string,          // 特别提醒，如"绝对禁酒"，空则不渲染
  photoData: string,      // 药品照片 dataURL（≤5MB），空则回落 SVG 图标
}
// 成员（一位家人一份独立药单）
{ id: string, name: string, title: string, drugs: Drug[] }
// 应用状态
{ members: Member[], selectedId: string }   // 默认内置 爸爸（爷爷示例药单）/ 妈妈
```

时段固定枚举 `早/中/晚/睡前`；预览区按此时段分组，空时段整块隐藏。

## 关键实现点

1. **实时预览**：单一状态源，编辑区每次输入即时反映到右栏卡片；桌面双栏、移动端上下（Tailwind 响应式 `lg:` 断点切换）。
2. **药片 SVG**：5 种外观全部手写内联 SVG 组件（无外部图片依赖，黑白打印不糊）。
3. **存图**：`html2canvas(cardRef).toBlob()` → `a[download]` 触发下载，2x `scale` 保证高清。
   - ⚠️ 已知风险：Tailwind v4 默认输出 `oklch()` 颜色，html2canvas 解析不了会导致导出变白。对策：卡片预览区内**只使用 `#hex` 颜色**（自定义 class 或内联样式），不使用 Tailwind 默认调色板。
4. **朗读**：`speechSynthesis`，`lang: 'zh-CN'`、`rate: 0.85`；按早→中→晚→睡前拼文案；再次点击 `cancel()` 停止。无中文语音的环境降级：`onerror` 时提示"当前浏览器不支持语音"。
5. **打印**：`window.print()` + `@media print` 隐藏编辑区与操作栏，仅打印卡片，A4 纵向、字号用 `pt` 单位。
6. **示例加载**：首屏默认选中爸爸成员；点击示例按钮整体替换当前选中成员的药单（覆盖前无确认——MVP 数据量小，接受丢失）。
7. **localStorage 持久化**：全部成员自动写入 `yao-ming-bai-members-v1`；照片先经 canvas 压缩为 ≤256px JPEG dataURL 再入库（内存态保留原图），配额超限/写入失败给出红字提示且不丢页面数据；损坏数据回落默认两位成员。
8. **只读分享链接**：把当前成员药单（标题+药品，不含照片 base64）编码为 base64url 塞进 `#share=`；带 hash 打开时进入只读模式（仅卡片 + 存图/朗读/打印），点「我是子女，我要修改药单」用 `history.replaceState` 去掉 hash 回编辑模式；只读模式不写 localStorage。

## 部署与交付

- `npm run build` 产出静态文件 → Qoder Sites 发布 → 共享权限设为 Public
- 无痕窗口验证免登录可访问，链接写入天池论坛提交帖
- 开发过程按 [参赛规则与项目清单.md](../参赛规则与项目清单.md) 留存 Qoder 截图

## 开发步骤
