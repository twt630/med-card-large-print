# 给爸妈的极简大字用药卡片生成器 — 产品设计文档

> 版本：MVP v0.1 ｜ 更新：2026-11-20 ｜ 状态：已定稿

## 一句话定位

把子女记录的用药信息，变成一张爸妈不用戴眼镜也能看清的 A4 打印卡片。

## 背景与问题

给爸妈整理用药时，常见做法是发微信文字或手写纸条，问题在于：

- 字太小，老人看不清，容易漏服/错服
- 信息零散，没有固定格式，每次都要重写
- 手机操作对老人不友好，纸质卡片贴在药盒旁最可靠

核心洞察：**爸妈用的是纸，不是软件。** 这个工具的交付物是一张打印纸。

## 目标用户

- **操作者**：子女（会基本电脑操作，负责录入和维护）
- **使用者**：爸妈（60+ 岁，视力衰退，只接触打印出来的卡片）

## 产品原则

1. **大字压倒一切** — 正文 ≥28pt，宁可信息少，不可字小
2. **极简** — 一条主线：输入 → 生成 → 打印；没有账号、没有网络依赖
3. **黑白友好** — 老人的打印机和生活场景下，黑白打印必须同样清晰
4. **一页原则** — 一张 A4 最多 3~4 种药；药多就分多张卡片

## MVP 功能范围

### 1. 单文件网页

一个纯 HTML 文件（内嵌 CSS/JS），双击本地打开即可使用，无需安装任何环境。

### 2. 用药录入表单

每种药录入以下字段：

| 字段 | 示例 | 必填 |
|------|------|------|
| 药名 | 氨氯地平 | 是 |
| 每次剂量 | 1 片（5mg） | 是 |
| 服用时间 | 早 / 午 / 晚 / 睡前（勾选） | 是 |
| 备注 | 饭后吃 / 漏服不补 | 否 |

支持添加/删除多条药物（上限 4 条，超出提示分页）。

### 3. 生成打印卡片

- A4 纵向布局，按时间段（早/午/晚/睡前）分格呈现
- 药名和剂量用特大字号，备注醒目（红色/加粗边框）
- 卡片顶部留"日期范围 / 贴药盒处"提示区

### 4. 打印 / 导出 PDF

调用浏览器原生打印对话框，直接打印或另存 PDF。

## 明确不做（Non-goals）

以下功能留给后续版本，MVP 一律不做：

- 多套卡片模板 / 主题
- localStorage 保存与恢复（MVP 每次重新录入）
- 图片、语音、扫码等多媒体
- 提醒闹钟、吃药打卡
- 账号系统、云端同步、多人协作

## 设计硬性要求

- 正文字号 ≥28pt，药名可到 36pt 以上
- 纯黑白打印不丢信息（颜色只做增强，不做唯一区分）
- 高对比度、无浅灰细线，避免老人分辨困难

## 成功标准

1. 子女在 3 分钟内完成 2~3 种药的录入并打印出卡片
2. 爸妈不戴眼镜能读清药名、剂量和时间
3. 卡片贴在药盒旁，两周内不模糊、不误读

## 后续方向（按优先级）

1. localStorage 本地保存，避免重复录入
2. 多药分页与"每日时间表"总览视图
3. 常见药名自动补全（离线词表）
4. 大按钮"老人自查模式"（只读展示）

---

技术方案备注：MVP 为单文件 `index.html`，无构建、无依赖，便于直接分发和长期维护。
