# 药明白 —— 给爸妈的极简大字用药卡片生成器 — 产品设计文档

> 版本：MVP v0.2（对齐 2026 Qoder 高校创造力大赛 Hack4Good 赛道）｜ 更新：2026-11-20 ｜ 状态：已定稿

## 一句话定位

子女帮爸妈把复杂药品说明书整理成一张"超大字、带药片图标、按时段分组"的极简吃药卡片，支持存图发微信、打印和慢速语音朗读。

## 背景与问题

给爸妈整理用药时，常见做法是发微信文字或手写纸条，问题在于：

- 字太小，老人看不清，容易漏服/错服
- 信息零散没有固定格式，多药同服时时段、忌口容易混淆
- 手机操作对老人不友好

核心洞察：**爸妈需要的是一张贴在药盒旁、一眼看懂的卡片；子女需要的是 3 分钟录入、一键发微信/打印的工具。**

## 目标用户

- **操作者**：子女（负责录入维护、存图转发、打印）
- **使用者**：爸妈（60+ 岁，视力衰退，看卡片或听语音）

## 产品原则

1. **大字压倒一切** — 药名超大字号、高对比度，适老化设计优先
2. **一条主线** — 输入 → 实时预览 → 存图/打印/朗读，无需账号与后端
3. **开箱即用** — 首屏默认加载示例，评委点开链接即可完整体验
4. **黑白打印友好** — 颜色只做增强，不做唯一信息区分

## 技术形态

- **纯前端单页应用**：React + Tailwind CSS，无后端
- **部署**：Qoder Sites 公开访问（大赛要求，评委免登录体验）
- **截图留存**：开发全程保留 Qoder 交互截图，作为参赛凭证

## MVP 功能范围

### 1. 整体布局与风格

- 温暖、干净、高对比度：暖白背景 + 深灰/纯黑大字 + 柔和时段主题色
- 桌面端"左编辑 + 右实时卡片预览"双栏；手机端自动上下布局

### 2. 顶部导航栏

- 标题「药明白 · 给爸妈的极简大字用药卡片」
- 2 个「一键体验示例」按钮：「爷爷的高血压+降糖日常」「妈妈的感冒消炎用药」，首屏默认加载第一个示例

### 3. 左侧编辑区（子女用）

- 可编辑卡片标题（默认"爸妈的每日吃药提醒"）
- 5 个常见药快捷添加：氨氯地平、二甲双胍、布洛芬、阿莫西林、维生素D
- 手动增删改药品，字段：

| 字段 | 说明 | 必填 |
|------|------|------|
| 药名 | 如"氨氯地平" | 是 |
| 服用时段 | 早/中/晚/睡前多选 | 是 |
| 每次用量 | 如"1片" | 是 |
| 餐时 | 饭前/饭后/随餐 | 否 |
| 药片外观图标 | 纯白圆片/黄色椭圆片/红白胶囊/蓝白胶囊/颗粒冲剂（SVG） | 否 |
| 特别提醒 | 如"绝对禁酒""忌吃西柚" | 否 |

### 4. 右侧卡片预览区（爸妈看）

- 实体纸质卡片质感，按 🌅早上 / ☀️中午 / 🌆晚上 / 🌙睡前 四色块分组；没药的时段自动隐藏
- 每条药展示：药片 SVG 图标 + 超大药名 + 醒目剂量标签 + 餐时标签；特别提醒用红色胶囊标签高亮
- 卡片底部免责声明："本卡片仅用于辅助整理用药日程，不构成医疗建议，请严格遵照医嘱服药。"

### 5. 底部操作栏

- **保存高清卡片图片**：html2canvas 导出高清 PNG 下载（发微信用）
- **慢速语音念一遍**：Web Speech API，中文、rate 0.85，按早中晚顺序朗读，可点击停止
- **打印**：调用浏览器打印对话框，输出 A4 卡片

## 明确不做（Non-goals）

以下功能留给后续版本：

- localStorage 本地保存（MVP 每次重新录入/加载示例）
- 账号系统、云端同步、多人协作
- 用药提醒闹钟、吃药打卡
- 药品数据库/智能校验（不做医疗判断）

## 评审对齐（大赛重点）

- **首页一键体验示例**：满足"评委点开即跑完核心流程"
- **5 步内操作说明**：将写入天池论坛提交帖（发帖截止 2026-11-30 18:00）
- **适老化设计**本身即评审维度之一

## 成功标准

1. 评委打开 Qoder Sites 链接，不登录、不看说明，30 秒内看懂并跑通全流程
2. 子女 3 分钟内录入 2~3 种药并生成卡片
3. 爸妈不戴眼镜能读清药名、剂量、时段和红色提醒

## 后续方向（按优先级）

1. localStorage 保存与恢复，避免重复录入
2. 多张卡片管理与"每日时间表"总览
3. 常见药名自动补全（离线词表）
4. 老人自查模式（只读 + 更大按钮）
